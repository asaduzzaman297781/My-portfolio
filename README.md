# Asaduzzaman — Student Portfolio

Responsive portfolio made with HTML, CSS and JavaScript.

## Preview
Extract the ZIP and open `index.html` in a browser.

## Personalize before publishing
1. Replace `your.email@example.com` in `index.html` with your real email.
2. Add your real LinkedIn and GitHub profile URLs.
3. Update skills and project details to match your experience.
4. Add a profile photo if you prefer (the current design uses an initial avatar).

## Publish free with GitHub Pages
1. Create a GitHub account and a public repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Go to Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/ (root)`, then Save.
5. GitHub will show your public website URL.

Google Fonts are loaded online; the website itself is static and needs no backend.
